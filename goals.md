# Цели на семестр

1. Научиться контейнеризировать приложение: подготовить для него `Dockerfile` и запуск через Docker Compose.
2. Настроить CI/CD в GitHub Actions, чтобы при каждом изменении автоматически выполнялись проверка кода, тесты и сборка проекта.
3. Автоматизировать настройку окружения с помощью Bash и Ansible и задокументировать воспроизводимый процесс запуска проекта.
