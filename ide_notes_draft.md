# Заметки о Git в VS Code

1. Панель Source Control показывает изменённые файлы и позволяет быстро открыть diff.
2. Встроенный редактор конфликтов помогает сравнить обе версии и собрать итоговый файл.
3. GitLens показывает историю строк и помогает понять, когда и зачем появилось изменение.

В терминале удобнее выполнять сложные операции с историей, например interactive rebase.
